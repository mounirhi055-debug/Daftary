# دفتري (Daftary) — منصة إدارة كريدي الزبائن لأصحاب المحلات

## المحتوى
- `index.html` — الصفحة الرئيسية + تسجيل الدخول (صاحب محل / موظف / إدارة)
- `register.html` — إنشاء حساب محل جديد (يبقى بانتظار موافقة الإدارة)
- `dashboard.html` + `js/dashboard.js` — لوحة تحكم صاحب المحل (الزبائن، الكريدي، التسديد، السلع، الإحصائيات)
- `admin.html` + `js/admin.js` — لوحة تحكم الإدارة (الموافقة على الحسابات، تحديد مدة التفعيل، التمديد، الإلغاء)
- `terms.html` / `privacy.html` — شروط الاستخدام وسياسة الخصوصية
- `css/style.css` — التصميم الكامل
- `js/db.js` — طبقة الاتصال بقاعدة البيانات (Firebase)
- `js/ui.js` — أدوات واجهة مشتركة (تنبيهات، نوافذ تأكيد، تنسيق الأرقام والتواريخ)
- `js/auth.js` — منطق تسجيل الدخول والتسجيل واستعادة كلمة المرور
- `js/pwa.js` + `sw.js` + `manifest.json` — تثبيت الموقع كتطبيق على الهاتف
- `firestore.rules` — قواعد أمان قاعدة البيانات
- `icons/` — الشعار وأيقونات التطبيق

## قاعدة البيانات
التطبيق يستخدم Firebase (Authentication + Firestore) لكل حسابات صاحب المحل والموظفين والإدارة، مع مزامنة فورية للبيانات بين الأجهزة. راجع `README-firebase.md` للإعداد الكامل، بما في ذلك طريقة إنشاء أول حساب إدارة.

## طريقة التشغيل
1. أنشئ مشروع Firebase واملأ `js/firebase-config.js` (راجع `README-firebase.md`).
2. افتح `index.html` في المتصفح، أو استضف الملفات على أي استضافة استاتيكية (Netlify, Vercel, GitHub Pages...).
3. للتثبيت كتطبيق على الهاتف: افتح الموقع من متصفح الهاتف ثم اختر "إضافة إلى الشاشة الرئيسية"، أو اضغط زر "تثبيت التطبيق" الذي يظهر تلقائياً عند دعم المتصفح لذلك.

## المزايا
- تسجيل حساب لصاحب المحل مع بقائه معلَّقاً حتى موافقة الإدارة.
- تفعيل الحساب من الإدارة لمدة محددة، مع إلغاء تلقائي للتفعيل عند انتهاء المدة.
- تنبيه لصاحب المحل عند اقتراب انتهاء الاشتراك، وإمكانية التمديد أو الإلغاء من الإدارة.
- حسابات موظفين بصلاحيات محدودة لكل محل.
- لكل محل قائمة زبائن وسلع خاصة به، معزولة تماماً عن باقي المحلات.
- تسجيل عمليات كريدي وتسديد لكل زبون، مع اختيار اختياري لسلعة من قائمة المحل لتعبئة المبلغ والملاحظة تلقائياً.
- حساب الرصيد المتبقي تلقائياً لكل زبون وللمحل ككل، مع إحصائيات فورية.
- بحث في قوائم الزبائن والمحلات (لوحة الإدارة).
- استعادة كلمة المرور عبر البريد الإلكتروني.
- سجل نشاط لكل العمليات المهمة على حساب المحل.
- تصدير كشف حساب الزبون كملف PDF.
- تصميم عصري متجاوب بالكامل بالعربية RTL، ويعمل كتطبيق ويب تقدمي (PWA).
