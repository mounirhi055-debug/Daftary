# ربط تطبيق "دفتري" بـ Firebase — دليل الإعداد

التطبيق الآن يستخدم Firebase للحسابات (تسجيل دخول + تفعيل من الإدارة)، بينما
تبقى بيانات الزبائن اليومية تعمل بالكامل بدون إنترنت بفضل التخزين الأوفلاين
المدمج في Firestore (تُزامَن تلقائياً عند توفر الاتصال).

## 1) إنشاء المشروع
1. اذهب إلى https://console.firebase.google.com → "إضافة مشروع" (مجاني).
2. من ⚙️ إعدادات المشروع → عام → "تطبيقاتك" → أضف تطبيق ويب (أيقونة `</>`).
3. انسخ كائن `firebaseConfig` الذي يظهر لك، والصقه داخل `js/firebase-config.js`
   مكان القيم النائبة (`PASTE_...`).

## 2) تفعيل تسجيل الدخول
من القائمة الجانبية: **Authentication** → **Sign-in method** → فعّل
**Email/Password**.

## 3) إنشاء قاعدة البيانات
من القائمة الجانبية: **Firestore Database** → **Create database** → اختر
**Start in production mode**.

بعد الإنشاء، افتح تبويب **Rules** والصق فيه محتوى ملف `firestore.rules`
المرفق مع المشروع، ثم اضغط **Publish**.

## 4) إنشاء أول حساب إدارة
لا يوجد نموذج تسجيل للإدارة داخل التطبيق (بشكل مقصود، لأمان أعلى). لإنشاء
أول حساب إدارة:

1. من **Authentication → Users → Add user**: أدخل بريد وكلمة مرور لحساب الإدارة.
2. انسخ الـ **User UID** الذي يظهر بجانب الحساب الجديد.
3. من **Firestore Database → Start collection**: أنشئ مجموعة باسم `admins`،
   وأنشئ داخلها وثيقة **معرّفها (Document ID) هو نفس الـ UID الذي نسخته**،
   ويكفي أن تترك حقلاً واحداً بسيطاً بداخلها مثل: `email` بقيمة بريد الإدارة.
4. الآن يمكنك تسجيل الدخول من تبويب "إدارة الموقع" في صفحة الدخول بنفس
   البريد وكلمة المرور.

لإضافة مشرف آخر لاحقاً: كرّر نفس الخطوات (مستخدم جديد في Authentication +
وثيقة جديدة في `admins` بنفس الـ UID).

## كيف يعمل التفعيل الآن؟
- صاحب المحل يسجّل حساباً → تُنشأ وثيقة في `shops/{uid}` بحالة `pending`.
- شاشة الدخول تبقى تستمع مباشرةً لحالة الحساب؛ بمجرد موافقة الإدارة (من أي
  جهاز، بمجرد اتصاله بالإنترنت) تنتقل شاشة صاحب المحل تلقائياً إلى لوحة
  التحكم (يحتاج جهاز صاحب المحل اتصالاً لحظتها ليستلم الإشعار).
- **إيقاف التفعيل قبل الموعد**: زر "⛔ إلغاء التفعيل" في لوحة الإدارة يغيّر
  الحالة فوراً على السحابة؛ يصل التأثير لجهاز صاحب المحل بمجرد اتصاله
  بالإنترنت (وليس فوراً إن كان يعمل أوفلاين في تلك اللحظة).
- **الانتهاء التلقائي**: كل حساب له `expiresAt`؛ إذا انتهت المدة يُمنع الدخول
  تلقائياً (يُفحص عند كل تسجيل دخول، ويعمل حتى محلياً بمقارنة التاريخ المخزَّن
  بساعة الجهاز).

## ملاحظة أمان
كلمات مرور صاحب المحل تُدار بالكامل عبر Firebase Authentication (لم تعد
مخزَّنة أو مُجزّأة يدوياً كما في النسخة السابقة المحلية).
